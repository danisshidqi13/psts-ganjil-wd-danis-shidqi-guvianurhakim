Tentang Saya

Halo, nama saya Danis Shidqi Guvianurhakim dari kelas X.U-4. Saya tertarik mempelajari teknologi digital dan cara membuat website yang dapat digunakan untuk menyampaikan informasi dengan jelas. Melalui pelajaran Web Design, saya belajar bahwa HTML berfungsi untuk membangun struktur halaman, sedangkan CSS dapat digunakan untuk mengatur warna, ukuran, jarak, dan desain agar tampilan website menjadi lebih menarik.

Target saya dalam PSTS Ganjil adalah menyelesaikan seluruh tahapan tugas dengan baik, teliti, dan sesuai aturan yang diberikan. Saya ingin semakin memahami proses penggunaan Git dan GitHub, mulai dari menyimpan perubahan melalui commit, membuat branch percobaan, melakukan merge, sampai mempublikasikan website melalui GitHub Pages. Dengan menyelesaikan proyek ini, saya berharap kemampuan web design saya dapat berkembang untuk membuat karya digital yang lebih baik.
